# Week 2 - Day 3 - TypeScript - Building a unique value at run time

A **unique value** is a value that no earlier run of the same code has used. This lesson shows the
three pieces that build one: `+` to join text, `Date.now()` for the current time, and
`Math.random()` for a random number.

## 1. Joining text with `+`

Between two pieces of text, `+` joins them into one piece. When one side is a number, `+` turns the
number into text first, and then joins. Nothing is added between the two pieces, so a space appears
only where you write one.

Print a word and a number, joined three ways:

```ts
// Join a word and a number with +, with and without a space.
const prefix = 'learner';
const number = 42;
console.log(prefix + number);
console.log(prefix + ' ' + number);
console.log(prefix + number + '@example.com');
```

**Output**

```output
learner42
learner 42
learner42@example.com
```

**Explanation:** The first line has no space, because `+` adds nothing of its own. The second line
has a space, because `' '` was joined in between. The third line joins three pieces, and the number
in the middle becomes text on the way. This is how the rest of the day builds an email around a
number.

[Week 1 - Day 5 - TypeScript](/learn/w1/d5/p1) introduced the **template literal**, which is text
in backticks with `${}` around each value. Build the same email both ways:

```ts
// Build the same email twice: once with +, once with a template literal.
const prefix = 'learner';
const number = 42;
console.log(prefix + number + '@example.com');
console.log(`${prefix}${number}@example.com`);
```

**Output**

```output
learner42@example.com
learner42@example.com
```

**Explanation:** The two lines print the same text, because the two forms do the same work. `+`
reads well for two or three pieces, and a template literal reads well when the text is long. Either
is fine, and this course uses both.

## 2. `Date.now()`

`Date.now()` returns the current time as a number of milliseconds since the start of 1970. A
**millisecond** is one thousandth of a second, so the number changes one thousand times a second.
Two runs that start a millisecond apart get different numbers.

Print the time, and build an email from it:

```ts
// Read the current time as a number, and build an email from it.
const now = Date.now();
console.log(now);
console.log('learner' + now + '@example.com');
```

**Output**

```output
1790134629851
learner1790134629851@example.com
```

**Explanation:** Your digits differ from these, because your run starts at a different moment. The
number has 13 digits, and it grows by one every millisecond, so a run made later always gets a
larger number. That is what makes it useful as part of a unique value.

## 3. `Math.random()`

`Math.random()` returns a decimal number between 0 and 1, and each call returns a different one. A
decimal is not readable as part of an email, so two more steps turn it into a whole number.
`* 1000000` stretches the range to 0 up to 999999, and `Math.floor()` rounds a number down to the
nearest whole number.

Print two random decimals, then a random whole number:

```ts
// Print two random numbers, then turn one into a whole number with up to six digits.
console.log(Math.random());
console.log(Math.random());
const n = Math.floor(Math.random() * 1000000);
console.log(n);
console.log('learner' + n + '@example.com');
```

**Output**

```output
0.9910865003019883
0.9430810001716421
170624
learner170624@example.com
```

**Explanation:** The two decimals differ although the code that made them is the same, because each
call of `Math.random()` produces a new number. Your digits differ from these on every run. The third
line is a whole number with up to six digits, which reads as part of an email.

## 4. Joining the time and a random number

`Date.now()` alone is enough when one test runs at a time. Playwright runs several tests at once,
and two tests can start in the same millisecond, so both would get the same time. Joining a random
number after the time makes that collision practically impossible. Build the value that the rest of
the day uses:

```ts
// Join the time and a random number, so that two tests started in the same millisecond still differ.
const email = 'learner' + Date.now() + Math.floor(Math.random() * 1000) + '@example.com';
console.log(email);
```

**Output**

```output
learner1790134631368307@example.com
```

**Explanation:** The text joins four pieces: the word `learner`, the 13 digits of the time, up to
three random digits, and `@example.com`. Two tests that start in the same millisecond share the
first two pieces, and the random piece tells them apart.
